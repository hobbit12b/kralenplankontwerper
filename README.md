# Kralenplankontwerper

Dit is een statische web app voor GitHub Pages. Je tekent op een 19x19 kralenplank, je kunt illustraties en foto’s importeren, en je ziet recente ontwerpen met mini previews.

## Snel starten lokaal
Open index.html in je browser.

## GitHub Pages
Zet de bestanden in een repo en zet GitHub Pages aan op de main branch, root map.

## Import tips
Standaard staat import op Illustratie. Dat werkt het best bij pictogrammen en tekeningen.
Bij illustraties met veel lichte grijstinten helpt het vaak om Wit plaatsen aan te zetten.
